# 拾云 Shiyun

基于 PySide6 开发的轻量级 SFTP 文件管理器与智能备份工具。

---

## 功能特性

- **SFTP 文件管理** — 连接远程服务器，浏览、上传、下载文件，支持拖拽操作
- **多连接管理** — 保存多个服务器配置，一键切换连接
- **智能备份** — 支持全量备份和增量备份（基于 mtime 对比，仅下载变化文件）
- **并行传输** — 多线程并行上传/下载，充分利用带宽
- **定时任务** — 基于 cron 表达式的定时备份，支持自动关机
- **备份组** — 将多个备份模板编为一组，一键批量执行
- **备份恢复** — 从本地备份一键恢复到服务器
- **备份日志** — 详细记录每次备份结果，显示新增/更新/跳过文件数
- **连接测试** — 保存前验证服务器凭据有效性
- **系统托盘** — 最小化到托盘后台运行，不打扰工作
- **单实例保护** — 防止重复启动

---

## 技术栈

- Python 3.10+
- PySide6（Qt6）
- Paramiko（SFTP）
- Croniter（定时调度）

## 备份功能使用手册

### 1. 创建备份模板

1. 点击侧边栏备份区域的 **"+"** 按钮
2. 填写以下信息：
   - **名称**：给备份起个名字，如"游戏存档备份"
   - **远端路径**：服务器上要备份的目录，如 `/home/user/saves`
   - **本地路径**：备份保存到本地的目录，如 `D:\Backups\saves`
3. 点击 **保存**

### 2. 全量备份 vs 增量备份

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| **全量备份**（默认） | 下载远端目录下所有文件，覆盖本地已有文件 | 首次备份、数据量小、需要完整副本 |
| **增量备份** | 仅下载新增或修改过的文件（基于修改时间对比） | 定期备份、数据量大、节省时间和带宽 |

#### 增量备份判断规则

- 本地不存在的文件 → 下载（标记为 **新增**）
- 远端修改时间 > 本地修改时间 + 2秒 → 下载（标记为 **更新**）
- 其余文件 → 跳过（标记为 **跳过**）

> 注：2秒容差用于兼容 FAT32 等时间精度较低的文件系统。

### 3. 手动执行备份

- 在备份模板上点击 **▶ 按钮** 即可立即执行
- 执行过程中会显示进度条和实时状态
- 完成后弹窗显示结果：成功/失败/跳过文件数

### 4. 定时备份

1. 编辑备份模板
2. 勾选 **启用定时**
3. 设置执行时间，支持以下格式：
   - **每天**：如 `0 2 * * *`（每天凌晨 2 点）
   - **每周**：如 `0 3 * * 1`（每周一凌晨 3 点）
   - **自定义**：标准 cron 表达式（分 时 日 月 周）
4. 可选：勾选 **备份完成后自动关机**

#### Cron 表达式速查

```
分  时  日  月  周
*   *   *   *   *
|   |   |   |   |
|   |   |   |   +-- 星期几 (0-7, 0和7都是周日)
|   |   |   +------ 月份 (1-12)
|   |   +---------- 日期 (1-31)
|   +-------------- 小时 (0-23)
+------------------ 分钟 (0-59)
```

常见示例：

| 表达式 | 含义 |
|--------|------|
| `0 2 * * *` | 每天凌晨 2:00 |
| `30 3 * * 1` | 每周一凌晨 3:30 |
| `0 0 1 * *` | 每月 1 号零点 |
| `*/30 * * * *` | 每 30 分钟 |
| `0 2,14 * * *` | 每天 2:00 和 14:00 |

### 5. 备份组

当多个备份需要一起执行时，可以创建备份组：

1. 在侧边栏点击 **"备份组"** 区域的 **"+"** 按钮
2. 输入组名，如"全站数据备份"
3. 勾选需要包含的备份模板
4. 可以为组设置独立的定时任务（组内成员的个人定时会自动禁用）
5. 保存后点击 **▶ 按钮** 一键执行全部成员备份

#### 备份组 vs 单独备份

| 场景 | 推荐方式 |
|------|----------|
| 多个相关目录需要同时备份 | 备份组 |
| 不同时间表的备份 | 单独模板各自定时 |
| 部分备份需要定时，部分手动 | 组合使用 |

### 6. 从备份恢复

当需要将本地备份恢复到服务器时：

1. 在备份模板上 **右键** → 选择 **"恢复"**
2. 确认恢复信息（本地路径 → 远端路径）
3. 系统会自动创建远端目录结构并上传文件
4. 完成后显示上传结果

> 恢复操作会覆盖服务器上同名文件，请谨慎操作。

### 7. 备份日志

每次备份（手动/自动/恢复）都会记录日志：

- **时间**：执行时间
- **名称**：备份模板名称
- **触发方式**：手动 / 定时 / 恢复
- **状态**：成功 / 失败 / 部分成功
- **文件数**：总处理文件数量
- **新增**：新下载的文件数（绿色）
- **更新**：修改后重新下载的文件数（橙色）
- **跳过**：无需更新跳过的文件数（灰色）
- **耗时**：备份执行时长

## 配置文件位置

所有配置存储在用户目录下：

```
~/.shiyun/
├── config.json          # 连接配置、备份模板
├── backup_groups.json   # 备份组配置
├── backup_logs.json     # 备份日志
├── shiyun.log           # 运行日志
└── shiyun.lock          # 单实例锁文件
```

## 注意事项

1. **首次使用建议先测试连接**，确认服务器凭据正确
2. **增量备份依赖文件修改时间**，如果服务器时区与本地不同可能导致判断偏差
3. **定时任务需要程序保持运行**（可最小化到系统托盘）
4. **自动关机功能**仅在定时备份完成后触发
5. **网络不稳定时**建议适当降低并行线程数
